## Advisors

This project is advised by the client's advisors: the team charter is the `team-charter` skill, and each advisor is a skill of its own. These are the facts about this project they read before anything else. Replace each line's text after the colon with this project's facts.

- **The product:** what it is, who it is for, and how far it has got, for example before its first users, with named testers.
- **The records:** three folders at the project's root: `product/`, what is known of the product today; `history/`, what happened and why; `work/`, what is in hand. Records with a shape are written through the team charter's writer, `team.py`, run at the project's root; `team.py glossary` prints the glossary.
- **Keeping the folders:** where this project's rules for the three folders are written, for the working session: what goes in each, who updates it and when a file leaves.
- **Building rules:** the rules every change follows, for example the simplest thing that works, built soundly; local state before a backend; one file before a folder; extract on the third use, not the first.
- **Checks:** the check every change passes before it is done, for example `pnpm exec tsc --noEmit`.
- **Screens:** the platform the screens run on, for example a web app used on an iPhone.
- **Decisions about the advisors:** `history/DECISIONS.md`, each decision between advisors or against one, with its prediction, and `product/RULES.md`, the rules grown from them, both written through `team.py`.
- **Advisors of this project's own:** none, or each one with what it owns and where it speaks in the order.
